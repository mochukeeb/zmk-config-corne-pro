# MochuKeeb Corne Pro Firmware

ZMK firmware for the MochuKeeb Corne Pro.

## Branches

This repository intentionally has no `main` or `master` branch. Choose the branch
that matches the display installed on the keyboard:

| Branch | Display |
| --- | --- |
| [`niceview`](https://github.com/mochukeeb/zmk-config-corne-pro/tree/niceview) | nice!view |
| [`oled`](https://github.com/mochukeeb/zmk-config-corne-pro/tree/oled) | OLED |

Do not flash firmware from the other display branch.
